# 深度阅读：ROAM: Bridging Vision-Language Reasoning and Learned Control for Legged Navigation in the Wild

> 📄 对应论文：[ROAM: Bridging Vision-Language Reasoning and Learned Control for Legged Navigation in the Wild](https://arxiv.org/abs/2611.25215)
> 整理者：@CGmoke
> 最后更新：2026-11-24

---

## 1. 问题与动机

**要解决什么**：让四足机器人在非结构化野外环境里**自主决定往哪走**，而不只是「能走」。作者用一个很朴素的观察切入：让一个没有经验的人远程遥控同一台机器人，人也能把路走通——说明瓶颈不在运动能力（locomotion 已被近年腿式 RL 解决得不错），而在**决策「去哪里」的常识**。

**为什么难**：传统导航依赖几何可通行性估计（2.5D elevation map + MPPI 之类），它对**非几何危险**无能为力：高草、水、泥在几何上可能是平的；也不理解「应沿规定步道走、别踩私人牧场」这类隐性社会规范。语义分割能补一部分，但依赖固定数据集/固定标签集，换环境就要重训。

**之前卡在哪**（§1.1 把 VLM 用法拆成一条抽象层级谱）：

| 抽象层级 | 代表做法 | 代价 |
|------|------|------|
| 直接出关节/电机指令 | 端到端 VLA | 需要海量示教；四足这种形态数据难采；大模型难以满足 50–100 Hz 高频控制 |
| 出连续 waypoint / 轨迹 | VLM 生成路径点 | 需要 VLM 自己做精确空间推理 + 深度估计 + 几何后处理，落地困难 |
| 从离散候选里选 | 选目标点 / 轨迹 / landmark | 每步都要查 VLM，延迟高；大尺度户外仍是开放问题 |
| 只出**语义标签 + 标量** | **ROAM** | 把空间推理完全外包给下游模块 |

作者的核心判断是：**当前 VLM 的空间推理不可靠，但常识推理可靠**。所以不该让 VLM 从「懂场景」一路包到「会走位」，而应把它钉在「语义顾问」这个位置上。

## 2. 核心方法

三段流水线，频率逐级升高（§1.2、§4.3–4.7）：

```
VLM（每 10 s，云端）
  └─ RGB 前/后相机 640×427 + prompt（任务/机器人能力/字段定义/近 3 次 memory + 近 3 次标签均值）
     → 语义标签 + 每标签三个 0–1 值：risk / steppable / preferred_area
        ↓ 开词汇分割（6 Hz，基于 Xu et al. 预训练模型，带 "other" 类）
        稠密语义图；每像素值 = Σ_label v_label · p_label（温度缩放 softmax）
        ↓ 投影到 2.5D 高程图（4 cm 分辨率，8×8 m，多图层）
        高频空间表征
        ↓
   ① 运动策略 locomotion（teacher–student RL，~50 Hz）：用 elevation + steppable 层选落脚点
   ② 局部导航策略 local navigation（RL，10 Hz，输出 base 速度与 yaw rate）：用 elevation + risk + preferred_area
        ↑
   全局规划器：卫星图 GUI 点 waypoint → OpenRouteService（含瑞士徒步路网）→ 2–5 m 间隔 LLA 路点
   定位：Graph-MSF 因子图融合 IMU / RTK-GNSS / LiDAR-SLAM SE(3) / TSIF 惯性-运动学里程计
```

几个我认为设计得聪明的地方：

- **三个字段正交**：`risk`（该不该避开）、`steppable`（脚能不能踩）、`preferred_area`（该不该优先走）。草地是「非偏好但非高风险」，所以机器人平时沿步道走，遇到路被挡时**仍可以抄近路穿草地**（§2.3 Exploration）——这是单一 traversability 分数做不到的。
- **虚拟高度增量实现「偏好」**（§4.6）：把 Lee et al. 用于避人的技巧泛化——当机器人处在 preferred 区域时，把周围非偏好区域的高程人为抬高，让局部导航策略自然绕开；**当机器人已经在非偏好区时则不抬高**，保证它还能从当前位置走出来。用几何量编码语义偏好，避免了改 RL 的 reward。
- **抽象观测规避 sim-to-real**（§1.2、§4.5）：两条 RL 策略都在仿真里训练，但输入是 height scan、steppable scan、risk map 这类**易随机化的抽象量**，不需要照片级真实感渲染。运动策略用 Perlin 噪声随机生成可踩/不可踩区域，踩到不可踩区给 $-\alpha$（$\alpha=0.1$）惩罚；teacher 有特权信息（完美外感受、每足摩擦系数），student 加外感受噪声但**刻意不给 steppable scan 加大噪声**，防止策略学会忽略这个关键通道。
- **memory 机制**（§4.4、fig. S6）：把最近 3 次 VLM 输出的 memory 文本和最近 3 次标签值均值塞回 prompt，防止标牌离开画面后风险值立刻回弹。这是纯 prompt 层的时序一致性，不额外训练。
- **标牌检测是工程补丁**：VLM 每 10 s 才查一次，会漏掉瞬时信息；于是并行跑 YOLO 检测标牌，检测到就**暂停机器人**并把标牌区域裁进 VLM 查询（§4.4）。作者明说这是为绕开当前 VLM 延迟的临时方案，模型快了就该删掉。

## 3. 关键结果

**长距离徒步（§2.1、图 3）**：Zermatt 10.1 km / 1220 m 高差 / 最陡约 30% 坡度，从海拔 >3000 m 的 Gornergrat 下到 Furi，途经碎石、湖岸、高草、铁路、森林、沥青路；时间自主率 **96.7%**，2 次干预均因施工区分割失败（VLM 认出了 fence，分割没分出来，机器人撞了上去）。Seealpsee 环湖 2.38 km，**97.5%**，3 次干预（湖边、湿滑陡坡、需人工抬过转门）。系统能识别湖水并贴边绕行、尊重私人牧场不穿越、随场景切换标签（"gravel_path" → "road"/"paved_road"）。

**受控赛道 1.2 km（§2.2、图 4）**，对比纯几何 Field Local Planner 与 ViNT：
- 全局路径被人为偏移进灌木/草地：ROAM 靠 preferred_area 留在碎石路上；几何基线盲跟随全局 waypoint，卡在灌木里需人工救。
- 路上放假人：ROAM 标为 "human" 绕开；几何基线踩到假人腿；ViNT 多次干预且无反应。
- 施工标牌："DANGER - ROAD WORK AHEAD..." → 把碎石路标高风险、草地标偏好，绕行草地；"END ROAD WORK - Merge Back to Path" → 恢复路面偏好，回到路上。两个基线都读不懂，几何基线进工地，ViNT 因预采目标图里没有工地而撞障碍并朝错误方向走进高草。

**动作抽象层级的定量证据（§2.4、表 1、图 6C）**——这是我认为全文最有价值的一张表。27 个人工标注场景，把 RL 导航策略换成 A\* 以只比较「图像里的路径生成」：

| 方法 | Safety | Preferred | 到达目标 |
|------|------|------|------|
| **ROAM A\***（输出语义标签） | **0.991** | **0.868** | **27/27** |
| 直线 | 0.900 | 0.550 | 27 |
| 轨迹标签 + ROAM risk | 0.880 | 0.519 | 3 |
| 均匀标签（不含 ROAM risk） | 0.740 | 0.418 | 4 |
| **VLM 直出像素坐标（prompt）** | 0.714 | 0.398 | **5** |
| VLM 直出像素坐标（goal） | 0.670 | 0.363 | 3 |
| 轨迹标签（不含 ROAM risk） | 0.639 | 0.302 | 3 |

Holm 校正的双侧 Wilcoxon 符号秩检验，ROAM A\* 对所有基线显著。定性上直出坐标的路径「横穿不安全地形、不尊重清晰边界」。结论：对当代基础模型，**把 VLM 定位成高层语义顾问，比让它生成具体低层动作更有效**。

**组件验证**：固定标签集在表 S3 里把 TartanGround IoU 从 0.827 压到 0.665、Sign 从 0.904 压到 0.612，量化支持「开词汇动态生成是必要条件」；prompt 消融显示同义改写几乎不掉点（0.842 / 0.867），去掉 guidelines 小幅下降（Sign 0.798），去掉显式文字指令只留 "DANGER" 仍达 0.841（表 S4），说明 VLM 不是在做 OCR 式的字符串匹配，而是把警告与场景里的物理障碍关联起来。

**VLM 选型（表 S2）**：TartanGround（372 仿真场景）上各家接近（gpt-4o 0.853 / gemini-2.0-flash 0.851 / gemma-3-27b 0.836）；但 Sign（12 张真实标牌图，需把文字指令 grounding 到具体物体）上差距拉开：gemini-2.0-flash 0.912、gpt-4o 0.790、gemma-3-4b 0.521、qwen-2.5-vl-7b 0.416。作者指出小模型**能读出 "DO NOT STEP" 的字，却指不准它对应哪块木托盘**——「语言→空间 grounding」是主要短板。

## 4. 批判性思考

**站得住的部分**：真机验证的强度在机器人领域少见（10 km 级、跨地形、含 GNSS 失效与动物干扰）；表 1 对「动作抽象层级」做了同场景、同目标、带显著性检验的对照，而不是只报 demo 成功率；补充材料把 5 次干预逐一归因（4 次分割错误、1 次物理障碍、0 次 VLM 语义错误），诚实地指出瓶颈不在自己主打的模块上；prompt 消融与固定标签基线把「开词汇是否必要」变成了可证伪的问题。

**需要打折扣的部分**：

1. **N = 1。** §4.1、§4.9 明确写了两次徒步和每条赛道对比每方法只跑一次，样本量由「野外可用时间与标注数据集大小」决定，**未做 power analysis**。96.7% / 97.5% 是时间占比的描述性统计，不是带置信区间的成功率；「ROAM 优于 ViNT」也只是一次赛道上的观察。假人避障是唯一做了 N=10 的重复实验（且结果只在补充材料里）。
2. **自主率的定义偏宽松。** 按时间算而非按距离或按「关键决策点」算，且干预被计入非自主时间但机器人停下等待人工的时段如何计时不清晰。10.1 km 里 2 次干预都集中在施工区这一同类失效上，说明**失效模式高度相关**，不能当作 10 km 独立同分布的样本。
3. **全局路径是人工给的。** 长距离任务要人在卫星图 GUI 上点粗略 waypoint，靠 OpenRouteService 生成 2–5 m 间隔的全局路点。作者把「VLM 读不懂全局地图」列为局限——所以系统更准确的定位是**语义增强的局部导航**，而非端到端自主探索。表 1 里 "Goal reached 27/27" 也是在给了目标坐标的静态图上做的。
4. **云端闭源 VLM + 4G。** 硬件里专门配了 Teltonika RUTX11 路由器与 SIM 卡来调 OpenAI API。这带来网络连通性、服务可用性、闭源权重三重依赖；野外部署恰好是网络最不可靠的场景。作者的回应是「架构模型无关，等开源权重 VLM 够强就上板」——方向合理，但**当前演示并未验证**这个替代路径。
5. **版本漂移影响可复现性。** 部署用 gpt-4-vision-preview，benchmark 用 gpt-4o，prompt 消融用 gemini-3.5-flash（因为前两者被厂商弃用）。作者把这解读为「模型无关」的实证，但同一篇论文里跨表格的绝对值其实不可比，且 gpt-4-vision-preview 已无法复现。
6. **语义与物理接触脱节（作者自陈，§3）**。当前抽象只捕获视觉危险，无法表达薄冰 / 深泥 / 松砾石之间需要物理交互才能分辨的细微风险；高层「常识」不接触真实物理。作者把这归为「下一代基础模型需原生处理本体感觉与触觉力信息」——这条正好是本期 Force2Act 的位置。
7. **未测的工况**：白天、能见度良好为主；浓雾、暴雨、夜间、强逆光未充分测试。作者主张混合架构可「优雅退化」到纯几何导航（因为底层策略还用 LiDAR / 双目建几何图），但这是**架构上的推断，没有实测**。
8. **社会规范的边界由 prompt 决定**：「不要踩私人牧场」这类判断来自 VLM 的互联网常识，既无显式约束也无验证，出错时没有硬安全兜底（施工区撞栅栏即是例证）。

## 5. 个人收获

- **「让模型做它擅长的事，把不擅长的事外包」是一条可迁移的架构原则。** 这里的具体形式是：VLM 做语义 → 分割做像素级 grounding → 高程图做空间记忆 → A\*/RL 做几何与控制。表 1 证明这个分工不是工程妥协，而是**性能来源**（0.991 vs 0.714）。做具身系统时，先问「哪个子能力是当前模型的短板」，再决定抽象层级，比一味增大模型更有效。
- **频率解耦是分层系统的真正价值。** 10 s / 6 Hz / 10 Hz / 50 Hz 四级：慢层可以容忍网络延迟与大模型推理，快层保持反应性。这与 Force2Act 的「全局力策略每 0.53 s 规划 + MoFE 每步调节」是**同构的思路**——两篇论文都在解决「慢规划与快物理不同步」的问题，只是一个在导航尺度，一个在接触尺度。
- **用几何量编码语义偏好**很值得记。`preferred_area` 没有改 reward，而是临时抬高非偏好区的高程，复用已有的避障机制；`steppable` 也没有改控制器，只是作为额外观测层加惩罚。这种「把新信息塞进已有接口」的做法比重训策略便宜得多。
- **读野外部署论文，先查三件事**：重复次数（N=1 还是 N≥10）、自主率的分母（时间/距离/决策点）、全局信息是否人工给定。这三条决定了「10 km 自主徒步」到底能说明什么。
- **和已有知识的连接**：与仓库里 RT-2 / OpenVLA（VLA 端到端出动作）形成路线对照；与 ScaleNav（06 方向已有卡片，靠数据量扩展导航）是「数据驱动」vs「语义先验驱动」的对照；teacher–student + 域随机化的运动策略与 11-sim-to-real 方向的 SimVLA、PEAR 同属「仿真训练 + 抽象观测迁移」范式；Graph-MSF / 退化感知 LiDAR SLAM 则是长距离部署容易被忽略但决定成败的工程底座。

## 6. 延伸阅读（可选）

- **Miki et al.（prior work [3, 7]）**：本文运动策略的直接前身，ANYmal 的鲁棒腿式运动 teacher–student 训练。
- **Lee et al.（[6]）**：本文局部导航策略的前身，PRM-RL 可通行性图 + 避人的虚拟高度增量。
- **ViNT（[27]）**：以目标图像为导航指令的视觉导航 Transformer，本文受控赛道基线。
- **Field Local Planner（[49]）**：纯几何局部规划基线，用于隔离语义信息的贡献。
- **Xu et al.（[69]）**：开词汇语义分割网络，把 VLM 标签变成稠密风险图的关键模块——也是补充材料里 4/5 次干预的失效点，最值得优先改进。
- **Graph-MSF / 退化感知 X-ICP（[77–81]）**：长距离 GNSS 失效下的多传感器因子图融合，表 S1 给出 APE 0.44 m 的定量结果。
- **本期 Force2Act 卡片**（`cards/05-manipulation/force2act-...`）：ROAM §3 自陈「高层常识与物理接触脱节」，Force2Act 从力反馈闭环给出底层答案，建议对读。
