## 🎯 一句话概括

不学"动作值"，改学"动作的导数"：用神经 ODE 建模动作在**机器人物理时间**上的向量场，每个动作都由上一个积分而来，于是轨迹连续性由构造保证——一个公式同时充当视觉运动策略、VLA/WAM 的动作头、以及 RL 的 actor，在 14 个真机任务上全部最优。

## 💬 讨论与备注

- **核心不是"用了 ODE"，而是"积分变量换成了物理时间"。** 扩散/流匹配也在解微分方程，但 $\tau$ 是无物理意义的生成时间；ODE Policy 让 $dt$ 就等于一个控制步，于是"积分曲线"就是"机器人真正走的轨迹"。
- **三个设计互相咬合，缺一不可。** 消融显示：去掉 contractive perturbation，1 epoch 成功率从 79.8% 掉到 58.4%；把 seamless chunking 换成"每块从实测状态重启"，掉到 47.8%。这两项都不是锦上添花，而是"从能跑变成跑得好"的关键。
- **它的收益与模型容量无关。** 参数量从 1.5M 扩到 48M，增益几乎不变（图 4C）——最小的 ODE 策略（92.5% @10 epoch）都超过最大的 FM-DiT（≤87.5%）。这说明收益来自**参数化方式**，不是来自更多参数。
- **适用边界作者自己划清了。** §9.3 坦率承认：在 model-free RL 的早期实验中，ODE 版本收益很小甚至有害，因为连续性也平滑掉了探索。它最适合"命令本身应当平滑"的场景（模仿示教、真机部署）。
- **一个隐性前提**：积分的是"期望动作"（发给底层控制器的目标），不是"实测状态"。用 UMI 或人类视频这类只有实测位姿的数据时，需要把场的速度接到 PD 的阻尼项上（§9.1），这是额外的工程改动，不是开箱即用。
