# action-dynamics

> 动作表示与生成方式本身的设计：策略学什么、怎么把观测变成一段连续的动作序列。
> 收录范围包括神经微分方程（ODE）、流匹配与扩散的动作头、动作分块（action chunking）、
> 以及动作空间与时间参数化的替代方案；纯算法层面的 RL 改进归在 [14-rl-adaptive-control](../) 主目录下。
