## 🎯 一句话概括

SimVLA 利用仿真生成的动作轨迹、视觉问答和策略执行轨迹训练视觉—语言—动作模型，在不使用真实机器人遥操作示范训练的情况下，实现向真实环境移动操作任务的零样本迁移。

## 💬 讨论与备注

任务进度是完成的预定义子目标比例，不等于整项任务成功率。“模拟厨房”在上述结果中指实体搭建的真实测试场景。ID 为接近示范分布的测试；OOD-pos 和 OOD-vis 分别改变位置/布局及视觉条件。

零样本迁移不表示无需现实工程：方法仍包含真实机器人系统辨识、人工技能 API 和预训练视觉语言模型。ID 条件下，每任务 200 条真实示范的基线平均任务进度为 67.8%，高于 SimVLA 的 54.4%，不能将结论推广为仿真训练全面优于真实数据训练。（来源：§2、§3、附录 H 表 13）
