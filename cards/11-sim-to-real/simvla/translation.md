## 摘要

大规模、多样化的数据集推动了大语言模型（LLM）和视觉语言模型（VLM）的成功。但机器人视觉—语言—动作模型（VLA）仍受到真实世界数据采集成本与复杂性的限制。虽然仿真提供了一种可扩展的替代方案，它在移动操作 VLA 仿真到现实学习中的潜力仍未得到充分探索。

我们提出 SimVLA，一个完全使用合成仿真数据、无需遥操作即可训练移动操作 VLA 的端到端框架。SimVLA 首先在两种互补的仿真数据集上预训练：SimAction 是通过组合原子技能生成的大规模机器人动作数据集，覆盖 35 类多样化移动操作任务；SimVQA 利用仿真器特权状态提供空间、几何与子任务层面的视觉语言监督。随后，我们在 SimAction 与 SimDeploy 的混合数据上进行后训练；SimDeploy 是通过在多种仿真环境中执行策略而收集的数据集。

我们在补货、倾倒和清洁等任务上评估 SimVLA，展示了向真实世界移动操作的零样本迁移，其中包括真实家庭环境。SimVLA 超过了使用 50 条域内真实示范训练的策略，表明仿真可以支持可扩展的仿真到现实移动操作。我们进一步展示了多种互补监督对于在 VLA 训练中有效利用仿真的价值。

> 译注：实验中的真实示范数量是每任务数量；主要比较指标为任务进度，不应统一改写为完整任务成功率。

## 1. 引言

大语言模型（LLM）和视觉语言模型（VLM）受益于大规模、异构数据集，这些数据广泛覆盖任务、物体与环境（Radford et al., 2021；Chen et al., 2022；Alayrac et al., 2022）。近期的视觉—语言—动作模型（VLA）将这种数据驱动范式扩展至机器人：策略以视觉观察与语言指令为条件，预测机器人动作（Zitkovich et al., 2023；Octo Model Team et al., 2024；Black et al., 2024, 2025；Kim et al., 2025；NVIDIA et al., 2025）。然而，与互联网规模的文本—图像数据不同，机器人动作数据采集昂贵、依赖机器人形态，而且任务与环境多样性有限。这种数据瓶颈在长时程移动操作中尤其严重。

移动操作从几个方面加剧了 VLA 训练的挑战。首先，它具有部分可观测性（Jauhri et al., 2024；Li* et al., 2025）：机器人可能需要在当前视野之外采取行动。其次，移动能力提高了动作空间维度，并使操作与导航紧密耦合（Honerkamp et al., 2023；Yang et al., 2024；Wu et al., 2025；Shan et al., 2026）。例如，即使操作策略本身具备足够能力，不合适的底盘位置仍可能导致任务失败。因此，移动操作 VLA 的学习需要广泛覆盖场景布局、观察视角与底盘—机械臂协调。通过真实遥操作收集这些数据十分困难（Fu et al., 2024），这促使我们将仿真视为可扩展的数据来源，前提是学到的策略能够迁移到真实环境。近期工作（Deshpande et al., 2026）已迈出初步步伐，但真实评估仍限于单一开门任务且性能有限，说明需要更有效的流程。

我们提出 SimVLA，一个用于长时程移动操作 VLA 训练的零样本仿真到现实框架。以往仿真数据流程主要生成或扩增动作轨迹；SimVLA 则利用仿真提供三种互补监督：动作轨迹、特权视觉语言监督，以及面向部署的策略执行轨迹，如图 1 所示。

首先，SimAction 提供大规模、多样化的合成机器人动作数据，无需遥操作，覆盖程序化厨房环境中的 35 类移动操作任务。它通过组合原子技能 API 生成任务轨迹，使相同任务结构能够应用于不同布局、物体与初始配置。其次，SimVQA 利用仿真真值，为 VLA 联合训练提供空间、几何与子任务层面的监督。第三，SimDeploy 包含多种仿真环境中的策略执行轨迹（Nasiriany et al., 2024；Kim et al., 2026；Pfaff et al., 2026），让模型接触场景布局更丰富、面向部署的轨迹。这些数据源共同使 SimVLA 对仿真的利用超出了单纯生成动作数据的范围。

SimVLA 分两个阶段训练。首先在 SimAction 上接受动作监督，在 SimVQA 上接受视觉语言监督；随后在多种仿真环境中执行策略以收集 SimDeploy，再在 SimAction 与 SimDeploy 的混合数据上后训练。我们发现，后者对泛化到未见过的真实环境至关重要。

我们在真实世界的长时程移动操作任务上评估 SimVLA，包括实体模拟厨房、茶水间与真实家庭。不使用真实世界数据训练，SimVLA 便能够迁移到未见过的真实环境。在示范采集环境中，它超过了使用 50 条真实示范微调的 π0.5 策略；在茶水间与真实家庭中，当两种基线性能均显著下降时，SimVLA 仍保持了稳健表现。这些结果表明，在仿真中结合动作、视觉语言与面向部署的监督，可以实现零样本仿真到现实移动操作。

## 2. 相关工作

### 用于训练 VLA 的数据

VLA 模型依赖将观察、语言指令与动作配对的大规模异构数据集，从而形成通用机器人策略（Collaboration et al., 2023；Black et al., 2024, 2025；NVIDIA et al., 2025）。然而，数据仍是核心瓶颈。机器人动作数据主要通过遥操作采集，扩展规模的成本高昂。

### 仿真到现实迁移

仿真因数据生成可扩展而广泛用于机器人学习，但仿真到现实的差距仍使零样本迁移面临挑战（Li* et al., 2025；Maddukuri et al., 2025；Nasiriany et al., 2026）。为此，相关方法通常依赖两种互补策略：系统辨识（Lin et al., 2025b；Sobanbabu et al., 2025）减小动力学失配；域随机化（Singh et al., 2024；Chen et al., 2026）让策略接触广泛的物理与视觉条件。我们将同时校准关节空间与任务空间行为的混合系统辨识，与广泛的域随机化结合起来。

### 合成数据生成

合成机器人数据通常通过在仿真中扩增少量源示范生成（Mandlekar et al., 2023；Garrett et al., 2025；Jiang et al., 2025；Li* et al., 2025）。这增加了数量，但所得分布仍受源示范限制。例如，通过拉动开启柜门的示范，可能无法迁移到需要其他关节运动方式、如旋转才能开启的柜门。

基于运动规划的方法无需遥操作即可生成合成数据，近期工作展示了较强的仿真到现实迁移能力（Deng et al., 2025；Tian et al., 2026；Deshpande et al., 2026）。然而，现有方法大多仅将仿真作为动作数据来源。

SimVLA 将仿真视为多种互补监督的来源：SimAction 通过组合原子技能 API 生成动作轨迹；SimVQA 从特权仿真状态生成空间、几何与子任务层面的视觉语言监督；SimDeploy 则在多种仿真环境中生成策略执行轨迹，使模型接触自身策略诱导的状态。因此，相较于主要利用仿真扩展动作数据的以往方法，SimVLA 同时利用动作、视觉语言与面向部署的监督，支持零样本仿真到现实 VLA 学习。

### 移动操作

虽然对真实任务十分重要，移动操作相比固定式操作仍研究不足。清洁、补货与整理既要求丰富接触的物体操作，也要求协调移动，以到达合适的观察视角与交互位姿。因此，移动操作比桌面操作更困难：策略行为同时取决于导航、底盘—机械臂协调与部分可观测性（Honerkamp et al., 2023；Lin et al., 2025a）。

以往工作常通过解耦导航和操作（Yang et al., 2025）、回放底盘轨迹（Nasiriany et al., 2026），或假定有利初始位姿（Chai et al., 2026）简化问题。这些选择降低了控制复杂度，却也限制了协调底盘与机械臂行为的学习（Yang et al., 2024）。近期工作已为移动操作生成合成数据（Deshpande et al., 2026），但真实部署在任务多样性与性能上仍有限。SimVLA 面向耦合底盘—机械臂控制下的端到端 VLA 学习，覆盖 35 类多样化实用任务，并评估向三种未见过的真实环境的零样本迁移。

## 3. SimVLA：合成数据生成与 VLA 训练

SimVLA 是一个完全基于合成仿真数据训练 VLA 策略的零样本仿真到现实框架。本文将厨房作为移动操作的代表性领域。框架首先构建程序化厨房场景（§3.1），再派生出三种互补数据：SimAction，通过技能组合与运动规划生成的大规模机器人动作数据（§3.2）；SimVQA，利用特权仿真状态提供空间、几何与子任务监督的视觉问答数据（§3.3）；SimDeploy，通过在多种仿真环境中执行学到的策略，生成的面向部署的数据（§3.4）。模型首先在 SimAction 与 SimVQA 上预训练，再在 SimAction 与 SimDeploy 的混合数据上后训练（§3.5）。

### 3.1 程序化厨房场景

大规模动作数据需要多样的环境、物体与初始配置。我们使用 Scene Synthesizer（Eppner et al., 2024）程序化生成厨房布局，并在 Isaac Lab（Mittal et al., 2025）中仿真全部场景。具体包括五种常见厨房：岛台式、L 形、半岛式、单墙式与 U 形。

每种布局内随机化家具高度、家具与物体摆放、橱柜配置及材质。每个物体类别均包含来自 Objaverse（Deitke et al., 2023）的多种形状变化，促进跨物体几何的泛化。更多细节见附录 A。

### 3.2 SimAction：合成动作数据

SimAction 是面向移动操作的大规模合成动作数据集。每条轨迹包含观察、语言指令及连续机器人动作——双臂末端执行器位姿和底盘速度，用于执行程序化厨房中的长时程任务。数据集包含约 20 万条轨迹、2,778 小时机器人数据，覆盖 100 个程序化住宅场景中的 35 类任务。无需遥操作，通过将原子技能组合为任务程序，再用运动规划将子任务目标转换为无碰撞机器人轨迹，即可生成数据。

#### 利用技能 API 生成任务

给定厨房场景，脚本化技能 API 为轨迹生成提供子任务级目标状态。API 包含抓取、放置、倾倒、煮制、开启、关闭、递送、导航与搜索，可组合成可复用的长时程任务规范。这些规范随后可应用到不同机器人、环境与物体配置中，自动大规模生成示范。

例如，“把杯子放入水槽”分解为搜索并导航至杯子、抓取杯子、搜索并导航至水槽、将杯子放入水槽。搜索对移动操作至关重要，因为它天然部分可观测：机器人必须先定位任务相关物体，才能与之交互。搜索技能 API 让策略在推理时只依赖视觉输入，主动寻找任务相关物体。具体逻辑见附录 B。

我们用 BODex（Chen et al., 2025a）自动生成抓取位姿，同时提供 GUI，供用户按需指定抓取偏好。同一 GUI 还支持以原子技能序列定义新任务，无需编写底层控制代码即可扩展任务。界面见附录 B。

#### 利用运动规划生成轨迹

轨迹生成前，我们进行混合系统辨识以减小仿真与真实机器人的动力学失配。以往方法常通过匹配关节空间轨迹辨识参数（Lin et al., 2025b）；由于策略在末端执行器空间工作，我们额外约束末端跟踪。完整流程见算法 1。

使用辨识参数后，建立并行环境并执行运动规划来生成 SimAction。给定技能 API 输出的子任务目标状态，使用 cuRobo（Sundaralingam et al., 2023）计算无碰撞轨迹。为支持机器人形态多样性，我们为 Anubis（Kang et al., 2025）、RB-Y1 和 ROBOTIS AI Worker 三种机器人生成数据。

### 3.3 SimVQA：来自仿真的视觉语言监督

VLA 需要视觉语言骨干理解空间关系、物体几何、子任务进度及机器人中心坐标。然而，现有仿真到现实 VLA 流程主要用仿真生成机器人动作轨迹（Tian et al., 2026；Deshpande et al., 2026），未充分利用仿真中的大量特权信息。

SimVQA 将仿真真值转换成视觉问答监督。对每个仿真场景与轨迹，自动生成有关物体位置、空间关系、几何属性、机器人状态与子任务进度的问答，得到约 100 万个样本。这在感知与动作之间提供了中间监督层，鼓励 VLM 骨干编码与下游控制相关的信息。

从真实示范中取得这些有空间定位依据的标注，需要昂贵的后处理（Chen et al., 2025b）；仿真则可从真值状态直接取得相同标注，无额外标注成本。全部模板见附录 F 表 6。

### 3.4 SimDeploy：面向部署的策略执行数据

虽然 SimAction 提供可扩展的动作数据，脚本化运动规划轨迹并不能充分覆盖学到的策略部署时遇到的状态。微小预测误差可能引起视角变化、底盘位姿偏差和抓取失败。为使模型接触这些由策略自身诱导的状态，我们在 RoboCasa（Nasiriany et al., 2024）、MolmoSpaces（Kim et al., 2026）、SceneSmith（Pfaff et al., 2026）等多种仿真环境中零样本执行 SimVLA，构建包含 2.2 万条轨迹、460 小时数据的 SimDeploy。

SimAction 由脚本化技能组合与运动规划产生；SimDeploy 则捕捉学到的策略自身造成的分布变化，包括多样视角与场景布局。我们发现，在 SimDeploy 上后训练可以提高对未见真实环境的鲁棒性与泛化。

### 3.5 SimVLA：两阶段 VLA 训练

SimVLA 基于预训练 VLM（Beyer et al., 2024）和流匹配动作专家，沿用 π0.5（Black et al., 2025）的模型结构，分两个阶段训练。

预训练时，在单次前向传播中联合优化三项仿真目标：SimAction 连续动作的流匹配、SimAction 离散化动作 token 的自回归预测（Pertsch et al., 2025），以及 SimVQA 答案的自回归预测。这一阶段使 VLM 骨干与机器人动作对齐，同时保留视觉语言表征。为防止随机初始化动作头的不稳定梯度损害预训练骨干，此阶段阻断从动作头流向骨干的梯度（Driess et al., 2025）。

后训练时，在 SimAction 与 SimDeploy 的混合数据上优化流匹配目标。动作头已在预训练中预热，因此允许梯度更新 VLM 骨干。我们有意选择 π0.5 风格架构，使实验能够隔离所提出仿真数据与监督的影响。具体目标与配置见附录 G。

## 4. 实验

### 4.1 仿真实验

我们在程序化生成、未见过的 SimVLA 厨房与 MolmoSpaces（Kim et al., 2026）中，使用 RB-Y1 将 SimVLA 与 MolmoB0T（Deshpande et al., 2026）比较，两者均零样本评估。此外，还用 Anubis（Kang et al., 2025）评估八项长时程任务，见表 12。

### 4.2 真实世界实验

我们评估五项长时程移动操作任务：将杯子、碗、瓶子放入水槽，将碗放入抽屉，以及从瓶子向杯子倾倒，如图 3 所示。这些任务覆盖不同挑战，包括导航至容器、与关节物体交互、底盘—机械臂协调及双臂倾倒。

全部真实实验使用 Anubis：一个具有两条 6 自由度机械臂、平行夹爪及三轮全向底盘的双臂移动操作平台。评估环境包括实体模拟厨房、茶水间和真实家庭（图 4）。模拟厨房设三种条件：分布内（ID），即基线数据采集环境；OOD-pos，重新摆放物体和家具；OOD-vis，随机改变背景与照明。

基线为在每任务 50 或 200 条模拟厨房数据上微调的 π0.5。所有方法使用相同观察/动作空间、提示词与试验流程。我们报告任务进度，即已完成预定义子目标的比例。模拟厨房与茶水间中，每个任务—策略组合评估 20 次；真实家庭中每组合 10 次，总计 2,120 次策略执行。子目标、任务进度的具体定义及二元成功率见附录 H。

### 4.3 SimVLA 能否匹配使用域内示范训练的策略？

在我们评估的设置中，可以。我们将完全在仿真中训练的 SimVLA，与每任务使用 50 或 200 条域内真实示范微调的 π0.5 比较。如图 5，SimVLA 达到 54.4% 的平均任务进度，超过使用 50 条域内真实示范微调的 π0.5。

在 OOD-pos 和 OOD-vis 下，域内基线明显退化，而把真实示范从 50 条增加至 200 条带来的收益有限。这表明，仅增加域内数据未必能提供分布外移动操作所需的覆盖；SimVLA 则受益于更广泛的合成变化。

### 4.4 SimVLA 是否需要预训练？

需要。我们将 SimVLA 与跳过预训练的变体比较：该变体在相同的 SimAction—SimDeploy 混合数据上，仅使用后训练目标训练。如图 5，去掉预训练使性能显著下降。

这一发现与利用大规模真实机器人数据及多模态互联网数据预训练的以往工作一致。不同之处在于，SimVLA 的预训练数据 SimAction/SimVQA 完全来自仿真。

尽管 π0.5（Black et al., 2025）已展示较强的未见环境泛化能力，将其预训练检查点适配至新任务或机器人形态，通常仍需额外采集数据并微调。这些数据在特定环境中收集，因此环境变化时微调策略可能明显退化。实验中，每任务 200 条真实示范微调的 π0.5 在模拟厨房 ID 达到 67.8% 任务进度，在茶水间与真实家庭却仅为 21.3% 与 29%；SimVLA 则在三种真实环境中保持较一致的表现。

### 4.5 预训练数据消融

我们比较预训练时去掉 SimVQA、TokSimAction（离散化 SimAction），或同时去掉两者的变体。如图 6，去掉任意组件都会使全部五项任务表现下降，完整模型最佳。定性观察中，未用 SimVQA 预训练的模型常因抓取不够精确而失败，说明 SimVQA 为下游操作提供了有价值的空间监督。

为进一步研究这一效果，我们在 1,369 组留出的 SimVQA 问答上评估。表 11 中，完整模型的三维位置误差中位数仅 0.06 m，跨视角 IoU 为 0.61，显著优于消融变体。这说明 SimVQA 预训练赋予模型超越动作预测的准确空间推理能力。

### 4.6 后训练数据消融

图 6 将 SimVLA 与后训练时去掉 SimDeploy 的变体比较。SimDeploy 明显改善将杯子、碗、瓶子放入水槽，以及将碗放入抽屉等任务，因为它加入了包含不同布局、视角和重试行为的部署轨迹。

但它对从瓶子向杯子倾倒的收益较小。这与各任务所需变化相符：倾倒主要要求物体级泛化，而 SimAction 随机化已覆盖这种变化；水槽与抽屉任务则需要更广泛的场景级变化。

### 4.7 什么使分布外移动操作困难？

**轨迹覆盖有限。** 遥操作示范常仅覆盖狭窄的视角和接近轨迹，尤其是抽屉把手抓取等精确交互（图 7a）。采用动作块时，小误差可能把策略推入分布外状态；例如，将碗放入抽屉时略微过度旋转，就可能使夹爪偏离把手而抓取失败。因此，在模拟厨房 OOD-pos 条件下（图 4e），真实示范训练的策略大多无法抓住把手。

相反，SimVLA 通过子目标域随机化产生更多样的视角和空间配置（图 7b），表现更稳健。这说明有限的轨迹覆盖是分布外泛化的关键瓶颈，大规模仿真可以缓解这一限制。

## 5. 结论

我们提出 SimVLA，一个完全基于仿真数据训练移动操作 VLA 的零样本仿真到现实框架。通过结合程序化厨房场景生成、混合系统辨识、域随机化与 SimVQA 监督，SimVLA 无需遥操作即可生成大规模、多样化合成训练数据。

在多种仿真环境中执行策略收集的 SimDeploy，让策略接触程序化示范之外的场景级多样性和自身策略诱导状态，进一步缩小分布差距。五项任务与三种真实环境的实验表明，在本文评估设置中，完全在仿真中训练的 SimVLA 超过了使用 50 条域内真实数据训练的策略。无需环境特定数据，SimVLA 还可迁移至茶水间和真实家庭等实用场景。

与当前仿真到现实 VLA 基线的比较展示了 SimVLA 在移动操作设置间的泛化能力。此外，SimVLA 表明，在移动操作零样本仿真到现实 VLA 学习中，仿真不仅能提供动作轨迹，也能提供视觉语言监督与面向部署的策略执行数据。

## 6. 局限与未来工作

尽管 SimVLA 展示了移动操作的零样本仿真到现实迁移，仍有若干局限。第一，我们没有隔离各项域随机化因素的独立贡献。第二，任务集中于厨房类环境的刚性物体操作；扩展到柔性物体、灵巧操作和更广泛家庭场景仍属未来工作。

第三，SimVLA 是基于仿真的数据生成框架，而非跨机器人形态迁移方法或新 VLA 架构，因此评估仅覆盖部分机器人形态与架构。评估其通用性需要更广泛实验。最后，SimAction 依赖人工定义的技能 API；未来可利用 LLM 将技能扩展为代码形式的策略，实现更自主的流程。

### 厨房布局

为增加结构与视觉多样性，我们采用 Scene Synthesizer（Eppner et al., 2024）的五种常见布局：岛台式、L 形、半岛式、单墙式与 U 形，如图 8。每种布局对应现实厨房中常见的独特空间配置。

### 物体

为稳健泛化至不同物体几何，SimVLA 为每个任务相关类别引入大量实例。如图 9，杯子、瓶子、桌子、碗、食物及餐具等类别的实例来自 Objaverse（Deitke et al., 2023），覆盖多种形状、尺寸、长宽比与材质。场景生成时，随机采样物体位姿、缩放与材质属性。

这种物体级多样性很重要：仅在少量实例上训练的策略容易过拟合特定几何，即使形状轻微变化也可能失败。

为简化场景构建，SimVLA 提供轻量 GUI，如图 10。用户指定厨房布局（如 L 形）、选择物体类别（如碗、瓶子），再将每个物体分配到语义放置位置（如“橱柜上方”“洗碗机上方”）。正式生成前显示已填充的物体列表，供用户检查与调整。

点击 `Generate Kitchen Scene`（生成厨房场景），即可实例化物体实例、位姿与材质均随机化的完整场景。这一界面支持快速扩大训练分布。

## 附录 B：技能 API

### 原子技能接口

SimVLA 定义了包含抓取、放置、倾倒、开启、关闭、导航和搜索的原子技能库。每项技能实现为由 `@skill_register` 装饰的 Python 函数；装饰器自动将其注册到任务组合框架，可立即用于长时程任务定义。抓取接口示例如下。

**代码清单 1：原子抓取技能。**

```python
@skill_register(name="grasp", arm="right")
def grasp(env, object_name, arm="right"):
    pose = env.grasp_db.sample(object_name, arm)  # 从 BODex 采样
    move_arm_to_pose(env, arm, pose.intermediate)  # 抓取中间位姿
    move_arm_to_pose(env, arm, pose.grasp)         # 最终抓取位姿
    close_gripper(env, arm)                      # 闭合夹爪
    return SkillStatus.SUCCESS
```

### 搜索技能 API

给定目标物体，脚本化专家使用其真值位姿与仿真器碰撞几何，分三阶段合成搜索轨迹。真值位姿只用于数据生成；推理时，SimVLA 仅凭视觉观察复现学到的搜索行为。

1. **旋转：** 原地转动，直到朝向物体前方的目标位置。
2. **接近：** 沿路径点前进到与物体保持一定距离的位置；每个路径点加入横向扰动，并进行碰撞检查，以增加接近路径多样性。
3. **对齐：** 在视场范围内扰动最终朝向，让物体出现在图像不同位置，而非总在中心。

### 抓取位姿选择

抓取技能集成 BODex（Chen et al., 2025a），为每个物体生成多样候选位姿。如图 12，GUI 按夹爪配置和机械臂侧别（左/右）组织并展示最多 200 个候选。用户可按需选择偏好位姿，自动生成的候选则提供广泛覆盖。人在回路中的选择有助于让示范反映真实可行的抓取行为，而非任意接触配置。

## 附录 C：混合系统辨识

准确的仿真到现实迁移要求仿真动力学接近真实硬件。我们联合最小化仿真与真实机器人之间的末端位置误差、末端旋转误差及关节空间均方误差（MSE），进行混合系统辨识并校准物理参数。

以往方法仅匹配关节空间轨迹（Lin et al., 2025b）；由于 SimVLA 在末端空间工作，我们额外约束末端跟踪。为加速搜索，在 Isaac Lab 中同时运行 4,096 个并行环境（图 13），将校准所需墙钟时间由数小时缩至数分钟。

算法 1 给出完整流程。从参数空间采样 K 个候选仿真环境，并依据 N 条校准序列的真实机器人跟踪信号评估。只有末端位置误差、末端旋转误差及关节 MSE 均满足对应阈值时，候选才被接受。

### 算法 1：混合系统辨识

**输入：** 参数空间 $E$；机器人模型 $M$；并行候选环境数 $K$；校准序列数 $N$；真实机器人 $R$；误差阈值 $\tau_p=0.03\,\mathrm{m}$、$\tau_r=0.2\,\mathrm{rad}$、$\tau_j=0.0025\,\mathrm{rad}^2$。

1. 执行 `Autotune(E, M, K, N, R, τp, τr, τj)`。
2. 采样候选参数，创建环境集合 $\mathcal{S}=\{\mathrm{SimEnv}(M,p_k)\mid p_k\sim\mathrm{Sample}(E)\}_{k=1}^{K}$。
3. 生成 N 条校准序列 $\mathcal{U}\leftarrow\mathrm{GenSeqs}(N)$。
4. 获取真实信号 $\mathbf{R}\leftarrow\mathrm{GetSignals}(R,\mathcal{U})$，包括位置、旋转与关节状态。
5. 初始化 $J^\star\leftarrow\infty$、$p^\star\leftarrow\mathrm{null}$、$\mathbf{e}^\star\leftarrow\mathrm{null}$。
6. 对每个候选 $k=1,\ldots,K$，获取仿真信号 $\mathbf{S}\leftarrow\mathrm{GetSignals}(S_k,\mathcal{U})$，计算下列误差与得分：

$$
e_p=\max_{n,t}\left\|S^{\mathrm{pos}}_{n,t}-R^{\mathrm{pos}}_{n,t}\right\|_2
$$

$$
e_r=\max_{n,t}\mathrm{QuatAngleError}\!\left(S^{\mathrm{rot}}_{n,t},R^{\mathrm{rot}}_{n,t}\right)
$$

$$
e_j=\mathrm{MSE}(S^q,R^q),\qquad J=\frac{e_p}{\tau_p}+\frac{e_r}{\tau_r}+\frac{e_j}{\tau_j}
$$

7. 若 $J<J^\star$，更新 $J^\star\leftarrow J$、$p^\star\leftarrow p_k$、$\mathbf{e}^\star\leftarrow[e_p,e_r,e_j]$，保留当前最优候选。
8. 遍历结束后，若 $\mathbf{e}^\star\preceq[\tau_p,\tau_r,\tau_j]$（逐元素检查），返回 $p^\star$。
9. 否则返回 `null`，表示最优候选仍超过某项阈值。

> 译注：正文将阈值条件概述为整个序列内均满足。算法实际以位置/旋转的最大误差与关节 MSE 进行检查；此处保留算法定义。步骤为中文等价重排，未改变计算过程。

### 消融研究

我们比较四种校准设置：无辨识（默认 URDF 增益）、仅关节空间误差、仅末端空间误差，以及混合目标。每种设置下，回放跨三类操作任务的十条留出真实轨迹，并对 Anubis 双臂取平均，测量真实与仿真机器人之间的末端位置差异。

| 目标 | L2 平均值（mm）↓ | L2 最大值（mm）↓ |

## 附录 G：SimVLA 训练

SimVLA 采用两阶段训练流程，基于预训练 PaliGemma VLM 骨干与流匹配动作专家。两阶段的区别在于启用哪些损失，以及是否允许梯度回流至 VLM 骨干。

### 预训练：知识隔离的联合训练

记一个样本的输入 token 为 $x=(x^p,x^f,x^c,x^a)$。其中，$x^p$ 为前缀 token，包含由 SigLIP 编码的图像块、语言指令与本体感知状态；$x^f$ 为经 FAST 离散化的动作 token（Pertsch et al., 2025）；$x^c$ 为 SimVQA 语言 token；$x^a=a^{\tau,\omega}_{1:H}$ 为带噪连续动作 token，定义为：

$$
a_i^{\tau,\omega}=\tau a_i+(1-\tau)\omega_i,\qquad \tau\sim p(\tau),\quad \omega\sim\mathcal{N}(0,I).
$$

流匹配动作专家 $f^a_\theta$ 以前缀和插值时间 $\tau$ 为条件，预测从带噪动作 $x^a$ 指向干净动作轨迹的向量场。SimVLA 采用 $H=50$、$d=23$。

为每个样本 $b$ 分配三个伯努利掩码 $M_b^a,M_b^f,M_b^c\in\{0,1\}$，分别决定是否对该样本应用流匹配、FAST 与 VQA 损失。我们沿用知识隔离框架（Driess et al., 2025），在单次前向传播中优化三个目标：

$$
\mathcal{L}_{\mathrm{flow}}(\theta)=\mathbb{E}_{\mathcal{D},\tau,\omega}\left[M^a\left\|(a_{1:H}-\omega)-f^a_\theta(x^a;x^p,\tau)\right\|^2\right].
\tag{1}
$$

$$
\mathcal{L}_{\mathrm{fast}}(\theta)=\mathbb{E}_{\mathcal{D}}\left[-M^f\sum_{j=1}^{n_f}\log p_\theta(x^f_j\mid x^p,x^f_{<j})\right].
\tag{2}
$$

$$
\mathcal{L}_{\mathrm{vqa}}(\theta)=\mathbb{E}_{\mathcal{D}}\left[-M^c\sum_{j=1}^{n_c}\log p_\theta(x^c_j\mid x^p,x^c_{<j})\right].
\tag{3}
$$

$$
\mathcal{L}_{\mathrm{pre}}(\theta)=\mathcal{L}_{\mathrm{flow}}(\theta)+\alpha_f\mathcal{L}_{\mathrm{fast}}(\theta)+\alpha_c\mathcal{L}_{\mathrm{vqa}}(\theta).
\tag{4}
$$

其中，$n_f$ 与 $n_c$ 分别为 FAST 动作与 SimVQA token 序列长度，且 $x^f_{<1}=x^c_{<1}=\emptyset$。因此，第一个 FAST 或 VQA token 直接根据前缀 $x^p$ 预测，后续 token 则根据之前的后缀 token 自回归预测。

为防止随机初始化动作专家损害预训练 VLM 骨干，我们采用知识隔离。具体而言，流匹配损失的梯度在 VLM 骨干参数 $\theta_b$ 处停止，而 FAST 与 VQA 损失正常更新骨干。另外修改注意力掩码，阻止连续动作 token 与 FAST/VQA token 之间的交叉注意力，保证三路监督在同一次前向传播中解耦。

### 后训练

动作专家在预训练中预热后，取消梯度停止，让流匹配损失可以反向传播至 VLM 骨干 $\theta_b$。此阶段去掉 FAST 与 VQA 损失，仅在匹配下游评估设置的移动操作任务上微调。目标为：

$$
\mathcal{L}_{\mathrm{post}}(\theta_b,\theta_a)=\mathbb{E}_{\mathcal{D}_{\mathrm{post}},\tau,\omega}\left[\left\|(a_{1:H}-\omega)-f^a_{\theta_b,\theta_a}(x^a;x^p,\tau)\right\|^2\right].
\tag{5}
$$

其中 $\theta_a$ 与 $\theta_b$ 分别为动作专家与 VLM 骨干参数，流匹配损失的梯度可同时更新两者。

训练数据为 $\mathcal{D}_{\mathrm{post}}=\mathcal{D}_{\mathrm{cont}}\cup\mathcal{D}_{\mathrm{deploy}}$。$\mathcal{D}_{\mathrm{cont}}$ 是预训练使用的原始连续动作数据；$\mathcal{D}_{\mathrm{deploy}}$ 是在多种仿真环境中执行策略得到、并匹配下游评估设置的移动操作部署数据。

动作专家已经预热，因此此时允许梯度流入骨干可以进行任务特定适配，同时避免从随机初始化动作专家开始联合训练预训练 VLM 表征时可能出现的不稳定。
