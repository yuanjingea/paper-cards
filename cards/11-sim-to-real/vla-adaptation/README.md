# vla-adaptation

> VLA 策略的部署期适配：在不重训练骨干的前提下，让预训练 VLA 跨越场景、本体与数据域的差异。
> 收录范围包括检索增强、推理时引导（inference-time steering）、测试时对齐等"冻结模型 + 外部信号"的路线；
> 依赖参数微调的跨域迁移归在 [11-sim-to-real](../) 主目录下。
