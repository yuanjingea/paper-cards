## 🎯 一句话概括

把「robot-use agent」当成「computer-use agent」的镜像：让一个开源 27B 推理模型（Qwen3.8-27B）只看相机画面与机械臂状态，用思维链推理后输出**下一个末端位姿**，**完全在仿真里用 RL（RURL）训练、不用一条示教**，就能零样本跨到没见过的仿真器、没见过的机器人，最终在一台从未训练过的真机双臂上做到 60%（基线 0%），同时九项通用能力基准不掉分。

## 💬 讨论与备注

- **它改变的不是「策略网络」，而是「谁来当策略」。** 模型不是 VLA，而是把推理模型本身当控制器：输出 JSON 格式的末端位姿增量，逆运动学与控制器在模型之外。因此换机器人只需改 prompt 里的机器人描述与坐标系，**不需要为新形态重新训练**——这是全文最关键的结构性差异。
- **「不用 harness」是刻意的对比项。** 同期大量工作（ORA、ASPIRE、Harness VLA、OpenRUA 等）给开源模型外挂分割模型、技能库、运动基元。本文主张这些组件应被模型内化，所以连 SAM 3 都不用，物体定位全靠模型自己从画面里读。
- **60% 的样本量只有 30 次试验（18/30）。** 二项分布下 95% 置信区间大约在 42%–76%，"60% vs 0%" 的定性结论很强，但"60%"这个数字本身不宜当作精确能力值引用。
- **能力几乎全部来自长思维链。** low effort 下只剩 21.9%——这意味着部署时的延迟与算力成本是硬约束，不是可以忽略的工程细节。作者把"缩短推理链而不掉点"列为未来工作，说明这一环还没解决。
- **作者自陈的四条局限都值得记**：没做 scaling（只训了 2 个仿真器、少量任务、27B 底座）；完全不用 SFT（缺同分布高质量数据 + 怕伤通用能力）；慢（单次移动最坏超半分钟）；不输出动作块（依赖控制器精度）。
