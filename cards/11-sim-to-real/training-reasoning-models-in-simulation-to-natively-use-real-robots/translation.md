## 摘要

机器人使用智能体（robot-use agent，RUA）已成为通往通用机器人控制的一条有前景的路径。然而迄今的强表现只由 GPT-6 Astra、Claude Fable 5.2 这类前沿闭源模型取得，而开源权重模型的能力明显偏弱。我们展示：**一个开源权重的 27B 推理模型可以被训练成原生地使用真实机器人——通过强化学习，完全在仿真中完成，且不使用任何示教。** 如同计算机使用智能体（computer-use agent，CUA），该模型观察环境、以思维链推理、并生成下一个末端执行器位姿，且不依赖任何 harness（外挂框架）。我们构建了 **PEAR**（Post-training Engine for Agentic Robotics，面向智能体机器人的后训练引擎），并用它在大规模仿真机器人任务上以 **机器人使用强化学习（robot-use reinforcement learning，RURL）** 训练该模型——这与前沿模型获得计算机使用能力的方式相对应。我们发现，在仿真中习得的技能可以很好地泛化到训练任务之外：它们迁移到**未见过的机器人**、迁移到**真实世界**、也迁移到**新的指令**。在仿真中于 LIBERO 与 RoboDojo 上训练后，该模型在我们的一台真实双臂机器人上成功率为 60%，而基座模型一次也没有成功。在 LIBERO 上，训练把成功率从 1.6% 提升到 74.4%，接近 GPT-6 Astra 与 GPT-6.1 Sol 在最大推理强度下的水平。与 π0.5——一个在示教上微调的视觉–语言–动作模型——相比，我们的模型对**任务本身**的变化要鲁棒得多：在 LIBERO-Pro 上，当在一个熟悉的场景中分配一个新任务时，π0.5 仅成功 0.75%，而我们的模型成功 57.4%。最后，该模型保持了通用能力，在九项推理、编程与视觉基准上没有可测量的退化。这些结果说明，机器人使用强化学习可以成为基础模型后训练的一个有前景的组成部分。

## 1 引言

机器人使用智能体（RUA）近来已成为通用机器人控制的一条有前景的方向。与从截图操作计算机的计算机使用智能体（CUA）相似，RUA 使用一个视觉–语言模型（VLM）观察机器人的相机图像、对任务进行推理，并输出下一个末端执行器位姿。由于 VLM 直接操作机器人，RUA 得以利用强基础模型广泛的 world knowledge 与强大的推理能力，从而能够泛化并完成复杂任务。

建立在 GPT-6 Astra、Claude Fable 5.2 等前沿模型之上的 RUA 已展现出卓越的泛化与语言跟随能力。在 RoboDojo 与 RoboLab 上，基于 GPT-6 Astra 的智能体已超过以往最佳策略。相比之下，在任务专属示教上微调的视觉–语言–动作模型（VLA）往往难以泛化到新目标、也难以跟随新指令。前沿 RUA 的表现可能有两个成因：这些模型被训练过计算机使用，并且它们有很强的空间推理能力。我们假设：**以思维链进行推理的能力对泛化尤为重要。**

然而，这样的表现迄今只由最强的闭源模型取得。开源权重模型在同一批基准上成功率很低，在一些简单任务上也会失败。若干工作构建 harness，在其中加入 SAM 3 这样的分割模型、把某些运动化为一小组选项等组件。这类 harness 能让开源模型完成部分任务，但它可能限制动作空间，从而使另一些任务变得不可行。随着模型能力增强，harness 的某些组件也可能被吸收进模型本身。

OpenAI 的计算机使用智能体这类系统是在计算机任务上用强化学习（RL）训练的，而两个场景的高度相似性提示：机器人使用也可以用同样方式学会。**因此我们用一个开源权重推理模型，以机器人使用强化学习（RURL）训练——完全在仿真中、不使用示教。** 为了支持这种长时序、多轮的 RURL 规模化运行，我们构建了 PEAR（Post-training Engine for Agentic Robotics），一个专为训练 RUA 设计的训练基础设施（§3.2）。在每一轮中，模型观察相机图像与机械臂状态、以思维链推理、并输出末端执行器的下一个位姿；逆运动学与控制器的运作在模型之外。

尽管模型完全在仿真中训练，它学到的技能能很好地迁移到真实世界。我们先把模型在 LIBERO 上训练，再在 RoboDojo 的两个任务上训练。随后，在一台它在训练中从未见过的真实双臂机器人上，模型完成了我们 60% 的试验，而基座模型一次都没有完成（§4.4）。仅在单臂 LIBERO 任务上训练的检查点也在 23% 的试验中成功。这些结果说明，基于仿真的 RL 可以赋予通用推理模型可迁移到未见真实形态的机器人使用技能。

我们的主要发现如下：

- **在 LIBERO 上逼近前沿模型。** 模型在 LIBERO 上从 1.6% 提升到 74.4%，超过 GPT-6.1 Sol 与 GPT-6 Astra 在中等推理强度下的表现（48.1% 与 49.3%），并在最大推理强度下把与它们的差距缩到很小（76.2% 与 80.6%；§4.1）。
- **鲁棒性与指令跟随。** 当训练任务被扰动时模型仍然鲁棒，并能跟随从未见过的指令。LIBERO-Pro 改变了 LIBERO 的目标与布局，在该基准上模型的 62.1% 超过 VLA π0.5 的 53.3%（§4.2）。
- **零样本迁移到未见任务与机器人。** 完全没有在 LIBERO-Long 上训练，模型在该套件上达到 39.0%，而基座模型仅 0.4%。在 RoboDojo 的两个双臂机器人任务上，仅在 LIBERO 上训练的模型成功率为 39.9% 与 17.0%，基座模型为 10.7% 与 13.0%。在 RoboLab-120 上，仅在 LIBERO 上训练把成功率从 5.4% 提升到 22.1%，而在 LIBERO 与 RoboDojo 上训练的模型在该排行榜上超过 π0.5 的条目（37.3% 对 28.0%；§4.3）。
- **仿真到真实迁移。** 技能也能从仿真零样本迁移到真实世界：不使用任何真实机器人数据，在 LIBERO 与 RoboDojo 上训练的模型在我们真实双臂机器人上的试验中成功 60%，仅在 LIBERO 上训练的模型成功 23%，而基座模型一次也没有成功（§4.4）。在这些试验之外，模型还能完成训练中从未见过的推理任务：它会在白板上画出一幅画的简笔线条版，并为检验某溶液是否碱性而选择合适的试剂（图 7c）。
- **保持通用能力。** 机器人使用训练在九项推理、编程与视觉基准上没有造成可测量的性能损失（§4.5）。这一结果表明 RURL 可以作为基础模型后训练的一个组件。

## 2 相关工作

**机器人使用智能体。** GPT-6 Astra 这类前沿 VLM 已在仿真与真实机器人上被作为 RUA 评测，RoboDojo 也把机器人智能体单独列为一个赛道进行排名。近期许多工作构建 RUA harness，提供感知工具、技能库、运动基元、记忆或代码执行，包括 ORA、ASPIRE、Harness VLA、OpenRUA、RAX、unirobot-agent 与 PyRUA-Lean。同期工作也在这样的 harness 内训练开源权重模型——PyRUA-Lean 中用 RL，CaPtain、AgenticRoboRL 与 ZAP 中先用监督微调再做多轮 RL。相比之下，**我们的模型不使用 harness、不使用示教**，仅用 RL 训练，并从仿真迁移到真实机器人。

**面向计算机使用智能体的 RL。** 计算机使用智能体从截图操作计算机，并在 OSWorld、WebArena 等基准上评测。OpenAI 报告其智能体先用监督学习、再用 RL 训练。开源权重智能体已在 Android 设备（DigiRL）、网页（WebRL）与桌面操作系统（UI-TARS-2）上用在线多轮 RL 训练。带可验证奖励的 RL 也被广泛用于训练长思维链。**在新任务上做 RL 对模型其它技能的侵蚀比监督微调更小，且泛化更好。** RURL 把这一配方应用到仿真机器人任务上，并把推理模型本身当作策略。

## 3 机器人使用强化学习

我们的目标是在仿真中训练一个推理模型去使用真实机器人。我们先描述机器人使用智能体如何操作机器人，以及我们在仿真与真实机器人上使用的协议（§3.1）；然后介绍训练基础设施 PEAR 及其运行的 RL 算法（§3.2）；由于基座模型起初极少成功，训练遵循一个课程（§3.3）。

### 3.1 机器人使用智能体

计算机使用智能体观察一张截图、对任务推理，并输出一次点击或一次按键，由操作系统执行（图 2 上）。我们的模型以同样的方式操作机器人（图 2 下）：每一轮它观察相机画面与机械臂状态、以思维链推理、并输出末端执行器的下一个位姿；随后逆运动学把该位姿转换为关节角，机械臂的控制器执行这次移动。

我们不使用感知工具、抓取或运动规划器、也不使用技能库，因此模型必须自己从相机画面中定位物体、决定如何接近与操作它们、并检测一次移动何时失败。早前的轮次与指令都保留在上下文中，因此每个决策都能把整个 episode 纳入考虑。模型通过仿真中的机器人任务 RL 获得所有这些能力（§3.2）。

系统提示词陈述了这一交互的协议、描述机器人的坐标系与相机，并给出任务指令（附录 H）。协议把机器人描述为一组具名部件与具名量：每个机械臂末端执行器的位置与朝向。状态列出每个量的当前值（一个 JSON 对象），动作是一个同结构的 JSON 对象，给出每个量的变化量（厘米与弧度）。控制器移动机器人，直到每个目标都到达且机器人静止，或直到机器人在未达目标处被挡住。episode 在仿真器报告成功时、在达到基准的步数上限或上下文的 token 预算时、或在响应中不含有效动作时结束。

**由于动作是一个位姿级目标且控制器位于模型之外，这一协议对每个机器人都相同**：只有部件列表与机器人描述在 LIBERO 的单臂 Franka、RoboDojo 的双臂 ARX 与真实的双臂 YAM 之间变化。因此部署到真实机器人无需进一步训练：模型通过同一协议行动，prompt 描述真实机器人的坐标系与相机，机器人自身的逆运动学与控制器执行动作。

### 3.2 PEAR：面向智能体机器人的后训练引擎

我们在 veRL 与 LMCache 之上构建 PEAR，一个用于训练 RUA 的基础设施。我们按照计算机使用的配方，在仿真中的机器人任务上用 RL 训练模型。令 $\tau=(o_1,y_1,\dots,o_T,y_T)$ 表示一个 episode，其中 $o_t$ 是第 $t$ 轮的观测，$y_t$ 是模型的响应（包含其推理与动作）。策略 $\pi_\theta$ 在上下文 $h_t=(p,o_1,y_1,\dots,o_t)$ 下逐 token 生成每个响应，其中 $p$ 是系统提示词。奖励 $R(\tau)$ 在 episode 结束时仿真器报告成功则为 1，否则为 0；训练在训练任务上最大化其期望。

我们使用 GRPO 的组归一化优势：采样共享同一任务与初始状态的 $G$ 个 episode $\tau_1,\dots,\tau_G$，并令

$$\hat A_i=\frac{R(\tau_i)-{\rm mean}_j R(\tau_j)}{{\rm std}_j R(\tau_j)+\epsilon}\tag{1}$$

其中 $\epsilon$ 是一个小常数。一个 episode 的每个生成 token——无论它属于推理还是动作、无论在第几轮——都获得该 episode 的优势；梯度估计在批内 $N$ 个生成 token 上取平均：

$$g=\frac1N\sum_i\sum_{t,k}\hat A_i\,\nabla_\theta\log\pi_\theta\big(y^k_{i,t}\,\big|\,c^k_{i,t}\big)-\mathbb{E}_{v\sim\mu(\cdot|c^k_{i,t})}\nabla_\theta\log\pi_\theta\big(v\,\big|\,c^k_{i,t}\big)\tag{2}$$

其中 $y^k_{i,t}$ 是第 $i$ 个 episode 第 $t$ 轮响应中的第 $k$ 个 token，$c^k_{i,t}=(h_{i,t},y^{<k}_{i,t})$ 是其上下文，$\mu$ 是生成该 episode 的策略。第一项是以组均值为 baseline 的 REINFORCE 估计，**不使用 PPO 裁剪**。rollout 与更新完全异步执行，因此 $\mu$ 落后正在训练的策略一到两个版本。第二项是针对这一不匹配的 score-centering 修正，我们单独使用该修正、不使用截断的重要性采样。与 DAPO 一样，所有 episode 都成功或都失败的组因其优势为零而被丢弃并替换。

因为训练是长时序、多轮 agentic RL，高前缀缓存命中率对高效 rollout 很重要。我们因此使用 LMCache 把前缀 KV cache 卸载到 CPU 内存，并限制并发 episode 数，以保持前缀缓存命中率在较高水平。策略更新时，整个 episode 构成一条训练序列；我们通过把 FSDP 与序列并行、梯度检查点结合起来，使其装入内存。附录 A 给出各类 GPU 上的配置。

### 3.3 训练课程

在二值奖励下，式 (1) 的优势只有在组内同时包含成功与失败 episode 时才非零，因此**一个模型永不成功的任务不提供任何学习信号**。训练开始时几乎每个 episode 都失败：基座模型在 LIBERO 的 Spatial、Object 与 Goal 套件上约 2% 的 episode 成功，在其长时序套件 LIBERO-Long 上 0.4%，在多数 RoboDojo 任务上几乎从不成功。

因此我们**先训练已经能提供信号的任务，并依靠迁移把能力扩展到其它任务**。在最初任务上学到的技能可以提升模型未训练任务上的成功率，一旦模型开始在这些任务上成功，我们就把它们加入训练。实验中训练分三个阶段：LIBERO 的 Goal、Spatial 与 Object 套件；然后是全部四个 LIBERO 套件；再然后是训练 LIBERO 之后信号最强的两个 RoboDojo 任务（general pickup 与 align blocks；§4）。**第一阶段排除 LIBERO-Long 也顺便提供了一个干净的迁移测试**（§4.3）。

## 4 实验

**训练。** 我们用 §3.3 的课程训练开源权重推理模型 Qwen3.8-27B：在 LIBERO 的 Goal、Spatial 与 Object 套件上 148 步，第 149 至 225 步在全部四个套件上，再在两个 RoboDojo 任务上训练 115 步。我们把第 225 步的检查点称为 **LIBERO-only 模型**，图中与表中记作 Ours (LIBERO only)。最后一个检查点是最终模型 **Qwen3.8-27B-PEAR**，我们把它部署到真实机器人上，记作 **Ours**。

**评测。** 在 LIBERO 上我们报告其 2,000 个评测 episode 上的成功率（40 个任务各 50 次）。LIBERO-Plus 从七个维度扰动 LIBERO：相机、光照、背景、传感器噪声、指令措辞、布局与机器人的初始状态（我们的模型 10,030 个 episode）。对 LIBERO-Pro，我们使用四类扰动（我们的模型每类 2,000 个 episode）：同场景不同任务、物体位置互换、指令改写、物体外观重绘。在 RoboDojo 中，我们评测 general pickup 与 align blocks，每任务 163 至 200 个 episode，并报告 95% Wilson 区间。RoboLab-120 由 120 个桌面任务组成，分三个难度级别，由带 Robotiq 夹爪的单臂 Franka 执行；我们每任务运行 10 个 episode（共 1,200 个），最终模型报告两次评测运行的均值。在真实双臂 YAM 上，我们对每个模型运行 30 次试验：在 5 个场景各 2 次，指令为"用三角板把三块积木推成一条直线且对齐，然后放下三角板并复位机械臂"；对 10 个物体各 2 次，指令为"把 ⟨物体⟩ 抬起 10 厘米"。**一次试验失败的条件是：超过 25 轮，或模型在单轮中推理超过 32k token。** 当模型输出逆运动学无法求解的无效动作时它会重试，重试也计为一轮。除非另行说明，我们的模型都在 xhigh 推理强度下运行。

**基线。** 前沿视觉–语言模型使用与我们的模型相同的协议（§3.1）：GPT-6.1 Sol 与 GPT-6 Astra 在 medium 与 max 两档推理强度下。推理强度是各模型自己控制"推理多久"的设置。π0.5 是一个在每个 LIBERO 任务的示教上监督微调的 VLA；我们不自行评测 π0.5，而使用其已发布检查点报告的结果（其 LIBERO 结果来自 openpi 仓库，LIBERO-Plus 结果来自 Yan 等人，LIBERO-Pro 结果是 Zhou 等人按套件的结果在四个套件上的平均）。在 RoboLab-120 上，我们与该排行榜上四个通用机器人策略比较：Cosmos3-Nano-Policy、π0.5、DreamZero 与 GR00T N1.6。四者都是在真实机器人数据集 DROID 上训练的检查点、并由 RoboLab 组织者评测，因此这里的 π0.5 与上面的 LIBERO 检查点不同。

### 4.1 在 LIBERO 上学习机器人使用

**RL 把策略从接近零的状态拉升起来。** 在 Goal、Spatial 与 Object 上基座模型约 2% 的 rollout 成功，因此几乎每个 rollout 都以无奖励结束。这三个套件上的训练成功率仍在 148 步内升到约 70%（图 3a）。在这三个套件上学到的技能也能很好地迁移到模型从未训练过的任务：在第 148 步（尚未在 LIBERO-Long 上训练时），模型解出 Long 的 39.0%，而基座模型为 0.4%（图 5a）。此时它在 LIBERO 整体上的成功率为 64.0%，我们在 §4.3 回到这一迁移问题。从第 149 步起在全部四个套件上训练，则把成功率提到第 184 步的 69.5% 与第 225 步的 74.4%，每段约 +5 点。**74.4% 使我们的模型接近 GPT-6 Astra（80.6%）与 GPT-6.1 Sol（76.2%）在最大推理强度下的水平，并在中等推理强度下超过二者（49.3% 与 48.1%）。**

这些结果表明，一个初始成功率很低的基座模型可以仅靠 RL 训到高成功率（本例中 1.6% → 74.4%）。它获得的能力也是通用的而非 LIBERO 训练任务专属的：后续小节显示，当 LIBERO 的场景与任务被扰动时模型仍然鲁棒、能跟随从未训练过的指令（§4.2），并能迁移到新基准、新机器人与真实世界（§4.3、§4.4）。

### 4.2 鲁棒性与指令跟随

仅在 LIBERO 上训练后，我们的模型就能泛化到训练任务之外：训练任务被扰动时它仍鲁棒，并能跟随从未见过的指令（图 4）。π0.5 在 LIBERO 上超过我们的模型（因为它在每个任务的示教上监督微调），但一旦任务目标或物体布局改变，它就失去了领先。我们在 LIBERO-Plus 与 LIBERO-Pro 上测试两个策略，二者以两个策略都未曾见过的方式扰动训练任务。LIBERO-Plus 主要扰动观测（相机、光照、背景与传感器噪声），两个策略在该基准上的损失相近：π0.5 掉 11.2 点，我们的模型掉 12.2 点。LIBERO-Pro 还改变目标与物体布局：我们在这里也掉约 12 点，而 π0.5 掉 43.6 点，于是它在 LIBERO 上 22.5 点的领先变成了 8.8 点的落后（图 4a）。

我们在 LIBERO-Pro 上的领先来自那些**改变机器人该做什么**的扰动。任务扰动保留训练场景及其初始状态，但给出另一个任务的指令：π0.5 从 LIBERO 的 96.9% 掉到 0.75%（掉 96.2 点），我们的模型从 74.4% 掉到 57.4%（掉 17.0 点；图 4b）。π0.5 倾向于执行它在该场景中被训练过的那个任务，而我们的模型执行新指令所要求的事。位置扰动从另一侧检验同一能力：它保留指令但交换物体位置，因此跟随指令现在需要不同的运动。π0.5 掉 76.1 点至 20.8%，我们的模型掉 16.9 点至 57.5%（图 4c）。π0.5 在另外两类扰动上仍然领先——那两类只改写指令或重绘物体外观、但保留原本的任务（图 10b）。因此，当"它被示范过的运动仍然正确"时 π0.5 保持鲁棒，而当运动必须改变时它就失败；我们的模型在每类扰动上损失 1 至 17 点，但始终跟随指令。**这一差异可能来自"模仿示教"与"对任务做推理"的分野：我们的模型保留了基座模型读取指令与场景的能力，而 RL 教它按照所读到的内容行动。**

### 4.3 零样本迁移到未见任务与机器人

在没有 LIBERO-Long episode 训练的情况下，我们的模型在 LIBERO-Long 上达到 39.0%，而基座模型仅 0.4% 的 episode 成功（图 5a）。RL 几乎不可能从基座模型学会 LIBERO-Long，因为一个几乎从不成功的模型几乎得不到奖励、也几乎没有可学的东西。**从其它三个套件的迁移改变了这一点**：当第 149 步把 LIBERO-Long 加入训练时，模型在其上的成功为 RL 提供了可训练的信号，其 LIBERO-Long 成功率升至 53.2%。

当仿真器与机器人都改变时，技能同样迁移。RoboDojo 是另一个环境，其任务使用双臂 ARX 而非 LIBERO 的单臂 Franka。**仅在 LIBERO 上训练**，我们的模型在 RoboDojo 的 general pickup 上成功 39.9%、align blocks 上成功 17.0%，而基座模型为 10.7% 与 13.0%（图 5b）。因此模型在 LIBERO 上学到的东西并不绑定于 LIBERO 的仿真器或其机器人。

我们还在第三个仿真基准 RoboLab-120 上零样本评测最终模型。它只在 LIBERO 与 RoboDojo 上用 RL 训练过，而 RoboLab 的任务与场景对它都是新的。它在 RoboLab-120 的 1,200 个 episode 中成功 37.3%，基座模型为 5.4%。这与 Cosmos3-Nano-Policy（36.8%）相当，并高于 π0.5（28.0%）、DreamZero（25.7%）与 GR00T N1.6（7.2%）——这四者都是 RoboLab 排行榜上在 DROID 数据集上训练的通用机器人策略（图 5c）。仅 LIBERO 的模型成功 22.1%。§D 按任务难度报告结果。

### 4.4 仿真到真实迁移

从 LIBERO-only 模型出发，我们继续**完全在仿真中**用 RL 在两个 RoboDojo 任务上训练。RL 在这里的表现与在 LIBERO 上一样——只是换了一个仿真器与一台双臂机器人：115 步内，两个任务上的训练成功率从约 25% 升到约 70%（图 6a）。在 RoboDojo 中评测，最终模型在 general pickup 上成功 71.2%、align blocks 上成功 78.8%，此前为 39.9% 与 17.0%（图 6b）。

随后我们在一台真实双臂 YAM 上零样本评测这些模型——这台机器人没有任何模型训练过。**不使用任何真实机器人数据，最终模型在 30 次试验中成功 18 次，而基座模型一次也没有成功。** LIBERO-only 模型在 30 次试验中成功 7 次，尽管它既没见过这些任务也没见过这台机器人（图 7a、7b）。最终模型的成功试验耗时 7 至 24 轮、使用 23k 至 132k token 的上下文；§G 列出每次试验及每次失败的原因。

**推理任务。** 上述试验重复了最终模型在 RoboDojo 中训练过的两个任务。我们另外给它两个**推理任务**——我们定义的推理任务是：在训练中没有对应物、且依赖"该做什么"的推理而非依赖已训练运动的那些任务（图 7c）。对这类任务，prompt 会详细描述机器人与任务（§5）。给定一幅《星月夜》的图片，最终模型在白板上画出了这幅画的简笔线条版；为检验某溶液是否碱性，它选择酚酞而非碘或乙醇，因为酚酞在碱性溶液中变红——加入试剂后溶液确实变红。这类任务需要 world knowledge 与推理能力，二者都来自基础模型。

### 4.5 保持通用能力

我们在同一批问题上用配对比较比较最终模型与基座模型。在全部九项基准上，95% 区间都包含零（图 8）。这与"在新任务上做 RL 比监督微调更不容易侵蚀模型其它技能"的发现一致。

最终模型在 RoboDojo 的 general pickup 与 align blocks 上达到 75.0% 的同时，在 AIME 2026 上得 98.5、GPQA Diamond 上得 89.7、LiveCodeBench 上得 88.4，并在每一项视觉基准上与基座模型相差不到两点。**同一个模型现在既能推理、写代码、回答关于图像的问题，也能使用机器人。**

### 4.6 推理强度与推理速度

尽管模型只在 xhigh 强度下训练，chat 模板中的推理强度设置仍控制它推理多久。没有任何 RL rollout 在更低设置下运行，然而在 low 强度下模型每轮只用 0.86k 思维 token 而非 3.23k（图 9a），因此**在单一强度上做 RL 并没有固定其推理长度**。它的成功率随该长度下降：在 LIBERO 上 low 强度为 21.9%（两次评测运行的均值），xhigh 为 74.4%。**用不到三分之一的思考，它只保住了不到三分之一的成功率**（图 9b）。因此它在 LIBERO 上能做的事，大部分来自于每次移动前的长时间推理。

因为模型在每次移动前都要长时间推理，它解码多快就决定了它能多快行动。使用 NVFP4 权重的量化与 DFlash2 草稿模型，它在 M5 Max 上以 Inco 的 Splash 引擎解码 52 token/s；配合我们的 megakernel，它在单张 RTX 5090 上解码 221 token/s、在单张 GB300 上 747 token/s（图 9c）。在 747 token/s 下，一轮 xhigh 推理约需 4.3 s，low 强度约需 1.1 s，因此推理强度设置也在成功率与速度之间做交换。我们使用 Inco 原始的 DFlash2 检查点，平均接受长度 3.2 token；专门为本模型调过的草稿模型可能有更长的接受长度，从而解码更快。因此该模型可以本地运行在单张消费级 GPU 或笔记本电脑上。然而 NVFP4 量化会降低我们模型的精度并拉长其思维链，因此所有评测都使用 BF16 权重。

## 5 局限

- **我们未能扩大训练规模。** 主要因为 GPU 资源有限，我们在训练两个 RoboDojo 任务之后就停下了（训练是稳定的）。目前的训练也只覆盖两个仿真器与少量任务，且从 27B 基座模型出发。我们相信，通过在更多样的仿真与更多样的任务上训练、并从更强的基础模型出发来扩大规模，可以得到更强的机器人使用性能。
- **我们没有使用监督微调（SFT）**，原因有二。第一，我们缺少高质量的分布内数据，并担心 SFT 会损害模型的通用能力。第二，我们认为机器人数据即便可得，也应当在预训练与中训练阶段加入，而不是用在一个已经完成后训练的模型上做 SFT。因此我们仅用 RL 训练。
- **我们的模型执行任务仍然很慢**，因为它在每次移动前长时间推理。RL 中我们没有施加长度惩罚，也不约束其思维链长度。推理速度虽高（单张 GB300 上 747 token/s），但一轮推理平均仍要 4.3 s（图 9），少数情况下思维链可达 32k token，使一次移动耗时超过半分钟。在不牺牲成功率的前提下缩短推理（例如在 RL 中奖励更短的思维链）留待未来工作。
- **我们的基座模型 Qwen3.8-27B 相对较小**，受其能力限制，它常常缺少关于自己所控制形态的知识，因此这类信息必须在 prompt 中提供。结果，任务成功率可能相当依赖模型能否从 prompt 中形成对形态与环境的清晰理解；当 prompt 给了它足够所需信息时模型表现最佳。对更难的任务（如图 7c 中的任务），我们的模型只在我们于 prompt 中详细描述形态与任务之后才成功。因此其性能相当依赖 prompt——但这也从一定程度上展示了它跟随详细语言指令的能力。
- **我们目前的模型还不能可靠地规划动作块**，因此它输出末端执行器的下一个位姿，再由逆运动学与控制器把机械臂移到该位姿并停在那里。精度因此部分取决于控制器：实现不佳的控制器在某些位置会让机械臂突跳并错过目标位姿，效率低的控制器会消耗任务的步数预算、留下更少的移动次数（这主要影响仿真评测）。这一设计也增加了任务所需轮数：由于每轮只把机械臂移到一个位姿，一个本来可以用一个动作块在一轮内完成的复杂运动，现在必须拆成几轮。我们希望未来工作能改进这一点。

## 6 结论

一个通用推理模型可以完全在仿真中学会使用真实机器人，方式与前沿模型学会使用计算机相同。它通过一个以相机画面为输入、以末端执行器位姿为输出的接口行动，并在机器人任务上用 RL 训练。**仅**在仿真中的 LIBERO 与 RoboDojo 上训练之后，我们的模型在我们真实双臂机器人的试验中成功 60%，而基座模型一次也没有成功。从一个极少在机器人任务上成功的基座模型出发，RURL 还产出了一个**能跟随从未训练过的指令、在训练任务被扰动时保持鲁棒、迁移到新仿真器与新机器人、并保持通用能力**的模型。因此，仿真中的 RURL 为真实世界的机器人使用智能体提供了一个简单的配方，且仍有可观的改进空间；我们的结果说明，推理使这类智能体能够很好地泛化到训练任务之外。我们希望这些结果能鼓励把 RURL 作为基础模型后训练组件的研究。

### H 提示词

系统提示词由一个对所有环境都相同的协议、一个针对具体基准的 ENVIRONMENT 段落，以及任务本身组成。模板如下，其中 `{environment}` 与 `{instruction}` 代表基准的 ENVIRONMENT 段落与任务指令，其余文本原样给模型。

> 你在控制一台机器人。每一轮你会看到机器人当前的状态与其相机图像，并回复下一个动作。
>
> ## OBSERVATION
> 机器人由具名部件组成，每个部件都有你可以设定的具名量。每一轮开始时先给出每个这样的量的当前值（按部件分组），随后是相机图像：
> `{"<部件>": {"<量>": <值>, ...}, ...}`
> 长度单位为厘米、角度单位为弧度；其它量是普通数值。除了这些名称之外，不会告诉你每个量对应什么。
>
> ## ACTION
> 动作以下列幅度改变所列的量：
> `{"<部件>": {"<量>": <变化量>, ...}, ...}`
> 写出每个量的变化；写 0 表示该量保持不变。
>
> ## EXECUTION
> 当每个目标都到达且机器人静止后，动作结束。如果有东西使某个目标无法到达，机器人会停在那里，动作随即结束。无论哪种情况，你随后会收到下一个观测。
>
> ## RESPONSE FORMAT
> 在你的回复末尾给出且仅给出一个包含该动作的围栏 json 代码块，其后不再有任何内容：
> ```json
> <动作>
> ```
>
> ## ENVIRONMENT
> {environment}
>
> ## TASK
> {instruction}

LIBERO 的 ENVIRONMENT 段落描述它的两个相机：

> − agentview：一个固定相机；机器人的基座位于其图像顶部，+x 指向图像下方，+y 指向其左侧。
