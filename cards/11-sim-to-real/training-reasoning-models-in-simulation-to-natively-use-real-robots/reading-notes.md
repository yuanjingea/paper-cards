# 深度阅读：Training Reasoning Models in Simulation to Natively Use Real Robots

> 📄 对应论文：[Training Reasoning Models in Simulation to Natively Use Real Robots](https://arxiv.org/abs/2611.18562)
> 整理者：@CGmoke
> 最后更新：2026-11-16

---

## 1. 问题与动机

**现象**：机器人领域正在分化出两条路线——VLA（在示教上微调，动作输出密集、泛化到新指令差）与 RUA（robot-use agent，让一个 VLM 看画面、推理、输出末端位姿，无需专门训练）。后者的强表现**目前只属于闭源前沿模型**（论文里的 GPT-6 Astra、Claude Fable 5.2），开源权重模型在同一批基准上成功率很低，连简单任务都会失败。

**为什么重要**：如果 RUA 的能力只能来自闭源前沿模型，那么机器人控制的"基座"就被锁在了 API 后面：不可本地部署、不可微调、不可审计、时延不可控。

**已有开源路线的做法是"外挂"**：ORA、ASPIRE、Harness VLA、OpenRUA、PyRUA-Lean 等给开源模型套一个 harness——接分割模型（如 SAM 3）、技能库、运动基元、记忆、代码执行。这能让模型完成部分任务，但**约束了动作空间**，使另一些任务变得不可行。

**本文的判断**：CUA（computer-use agent）已经有成熟范式——用 RL 在真实电脑任务上训。机器人使用与电脑使用在接口上高度同构（观测→推理→低层动作→系统执行）。既然如此，机器人使用也应该能被 RL 学会，而且**可以完全在仿真里学**。作者进一步猜测：前沿 RUA 的表现有两个来源，一是它们被训练过电脑使用，二是它们有很强的空间推理；而**推理能力（思维链）对泛化尤其关键**。

## 2. 核心方法

### （1）接口：把机器人当一台"电脑"

一轮交互（图 2）：

| | Computer-use agent | Robot-use agent（本文） |
|---|---|---|
| 观测 | 一张截图 | 相机画面 + 机械臂状态 |
| 推理 | 文本思维链 | 文本思维链 |
| 动作 | `click(812, 431)` / 按键 | 末端位姿增量（JSON） |
| 执行 | 操作系统 | 逆运动学 + 控制器 |
| 上下文 | 指令 + 所有历史轮 | 指令 + 所有历史轮 |

**协议是形态无关的**，这是全文最关键的工程设计：system prompt 把机器人描述为"一组具名部件及其具名量"；state 是这些量的当前值（JSON）；action 是**同结构**的 JSON，给出每个量的变化量（厘米/弧度）。控制器负责把机器人移到目标位姿并停下。

于是 LIBERO 的单臂 Franka、RoboDojo 的双臂 ARX、真机的双臂 YAM 之间**只差"部件列表 + 机器人描述"**。部署到真机不需要再训练：同一个协议、同一个 prompt 结构，只改坐标系与相机描述。

**没有 harness**：不用感知工具、抓取/运动规划器、技能库。模型必须自己从画面里定位物体、决定怎么接近和操作、判断一次移动是否失败。历史轮留在上下文里，所以每个决策都能考虑整个 episode。

### （2）PEAR + RURL：把 CUA 的 RL 配方搬到机器人上

- **PEAR**（Post-training Engine for Agentic Robotics）：建在 veRL + LMCache 之上的训练基础设施，专门服务长时序、多轮 agentic RL。
- **RURL**（robot-use reinforcement learning）：episode $\tau=(o_1,y_1,\dots,o_T,y_T)$，$y_t$ 含推理与动作；策略 $\pi_\theta$ 以 $h_t=(p,o_1,y_1,\dots,o_t)$ 为上下文逐 token 生成；**奖励是二值的**——episode 结束时仿真器报成功为 1，否则 0。
- **优势估计用 GRPO 的组归一化**：同任务同初始状态采 $G$ 个 episode，$\hat A_i=(R(\tau_i)-{\rm mean}_j R(\tau_j))/({\rm std}_j R(\tau_j)+\epsilon)$。**一个 episode 的每个 token（无论属于推理还是动作、无论在轮次）都拿该 episode 的优势**。
- 第一项是 REINFORCE（组均值作 baseline），**不用 PPO 裁剪**；第二项是 score-centering 修正，用来补偿 rollout 与更新完全异步导致的策略滞后（$\mu$ 落后 1–2 个版本）。像 DAPO 一样，全成功或全失败的组被丢弃重采（优势为 0）。
- 工程上：LMCache 把前缀 KV cache 卸载到 CPU 内存，让前缀命中率保持 95%+；整条 episode 作为一个训练序列，用 FSDP + 序列并行 + 梯度检查点塞进显存。

### （3）课程：从"有信号的少数任务"扩出去

二值奖励 + GRPO 有个直接后果：**只有组内同时有成功与失败时优势才非零**。而基座模型在 LIBERO 的 Spatial/Object/Goal 上只有约 2% 成功率、在 LIBERO-Long 上 0.4%、在多数 RoboDojo 任务上几乎为 0——**几乎不产生学习信号**。

策略是：先在**已经能产生信号**的任务上训，靠迁移把其它任务拉起来，等模型开始在这些任务上成功了再纳入训练。三阶段：

1. steps 1–148：LIBERO Goal / Spatial / Object（**故意不含 LIBERO-Long**）；
2. steps 149–225：四个 LIBERO 套件全部；
3. steps 226–340：RoboDojo 的两个信号最强的任务（general pickup、align blocks）。

第 1 阶段排除 LIBERO-Long 不是省事，而是**留出一个干净的零样本迁移测试**：第 148 步的模型从未见过 Long，却在 Long 上做到 39.0%（基线 0.4%）。这一设计值得借鉴——课程顺序顺便充当了消融。

## 3. 关键结果

### 主结果：LIBERO 上从 1.6% 到 74.4%

2,000 个评测 episode（40 任务 × 50）。训练 rollout 成功率在 148 步内从约 2% 升到约 70%；第 149 步加入 Long 后到 69.5%（184 步）、74.4%（225 步），每段约 +5 点。

对比前沿模型（同协议、各自 effort 设置）：GPT-6 Astra 80.6%、GPT-6.1 Sol 76.2%（max effort）；**但 medium effort 下二者只有 49.3% 与 48.1%**，本文 74.4% 明显超过。作者用这个对比论证"不是靠堆推理长度赢的"。

### 抗扰动：与 π0.5 的分岔点

两者**都只在 LIBERO 上训练**（π0.5 用示教 SFT，本文用 RURL）。在 LIBERO 上 π0.5 96.9% 领先 22.5 点；但换到扰动基准就翻转：

| 基准 | 扰动内容 | π0.5 | 本文 |
|------|----------|------|------|
| LIBERO-Plus | 观测层：相机、光照、背景、传感器噪声 | 掉 11.2 点 | 掉 12.2 点（**相当**） |
| LIBERO-Pro | 换任务（同场景同初始状态，换指令） | 96.9% → **0.75%**（掉 96.2） | 74.4% → **57.4%**（掉 17.0） |
| LIBERO-Pro | 换物体位置（指令不变） | 掉 76.1 点 → 20.8% | 掉 16.9 点 → 57.5% |
| LIBERO-Pro | 换措辞 / 换外观 | **仍领先** | 掉 1–17 点 |

作者的解读我认为是全文最有价值的一句：**观测层的扰动两者都扛不住（都是视觉问题），但一旦扰动改变了"机器人该做什么"，VLA 就崩了——它在那个场景里执行它被训练过的那个任务，而 RUA 会执行新指令。** 差异来自"模仿示教"与"对任务做推理"的分野。换措辞/换外观时 π0.5 仍赢，是因为"它被示范过的动作依然正确"。

### 零样本迁移（三层，逐层加难度）

1. **换任务**：LIBERO-Long 未训练，0.4% → 39.0%。
2. **换仿真器 + 换机器人**：RoboDojo（双臂 ARX），只训过单臂 LIBERO，general pickup 10.7% → 39.9%，align blocks 13.0% → 17.0%。
3. **换基准 + 对整个领域**：RoboLab-120（1,200 episode），5.4% → 37.3%；与 DROID 训练的通用策略比，≈ Cosmos3-Nano-Policy（36.8%），高于 π0.5（28.0%）、DreamZero（25.7%）、GR00T N1.6（7.2%）。

值得注意：**在 RoboDojo 上"只训过 LIBERO"的版本（39.9% / 17.0%）反而高于后来真在 RoboDojo 上训过的版本在对应任务上的起点**——训练之后是 71.2% / 78.8%。也就是说这两个任务本身可学，只是需要先把基础技能迁过去。

### 真机：60%，且没有一条真机数据

平台：真机双臂 YAM（训练从未见过）。试验设计：5 个场景各 2 次（"用三角板把三块积木推成一条直线，然后放下三角板并复位机械臂"）+ 10 个物体各 2 次（"把 ⟨物体⟩ 抬起 10 厘米"），共 30 次。

| 模型 | general pickup | align blocks |
|------|----------------|--------------|
| 基座 Qwen3.8-27B | 0/20 | 0/10 |
| 仅 LIBERO 训练 | 6/20 | 1/10 |
| 最终（LIBERO + RoboDojo） | **12/20** | **6/10** |

成功试验用 7–24 轮、23k–132k token 上下文。

**推理任务**（训练里完全没有对应物，靠世界知识）：给一张《星月夜》，在白板上画出简笔线条版；判断某溶液是否碱性时选酚酞而非碘或乙醇，因为酚酞遇碱变红——加了之后溶液确实变红。

### 通用能力不掉

九项基准（AIME 2026、GPQA Diamond、IFBench、LiveCodeBench v6、RealWorldQA、ERQA、MMMU、MMMU-Pro S/V）配对比较，平均变化 **−0.15 分**，95% 区间全部含 0。作者引用 Shenfeld 等人的结论：在新任务上做 RL 比 SFT 更不容易侵蚀其它能力。

### 成本与延迟

- LIBERO 上 low effort：0.86k token/轮 → **21.9%**；xhigh：3.23k token/轮 → 74.4%。**用不到三分之一的思考，只剩不到三分之一的成功率。**
- 单卡 GB300 747 tok/s 时，xhigh 一轮约 4.3 s，low effort 约 1.1 s；最坏情况思维链能到 32k token，单次移动超过半分钟。
- 训练总计约 **50,000 H100 等效 GPU 小时**；每个 RL 步 128 组 × 8 rollout；平均每个 episode 约 94k token（1.8k prompt + 92k response）、19.7 轮、39–59 张图。

## 4. 批判性思考

**站得住的部分**：迁移结论是"三层递进 + 真机"结构，很难用调参解释；LIBERO-Pro 的两种扰动给出了机制性解释（换任务 vs 换位置），且与 π0.5 形成清晰对照；"课程第 1 阶段排除 Long"顺便提供了干净的零样本测量；通用能力用配对检验而非单点比较。

**需要打折扣或追问的部分**：

1. **真机只有 30 次试验。** 18/30 = 60%，二项 95% 区间约 42%–76%。"60% vs 0%" 是强定性结论，但"60%"作为能力数值不该被精确引用。且只有 2 类任务、5 个场景，任务多样性很低。
2. **训练算力与"SOTA"之间的因果没被拆开。** 5 万 H100 小时的 RL 是极重的投入，而 π0.5 的 LIBERO 数字是引用已发布检查点、作者**没有自己复现**。两者的训练预算不可比，"74.4% 接近 80.6%" 这类跨模型比较的公平性有限。
3. **"不用示教"是修辞上更强、成本上更贵。** 作者自己在局限里说没做 SFT 是因为缺高质量同分布数据，也担心伤通用能力。但 5 万 GPU 小时换来的"无示教"，在工业场景里未必比"几千条示教 + SFT"划算——这条路线的经济性还没被讨论。
4. **强依赖 prompt。** 作者承认 27B 底座对自身形态的知识不足，形态与环境信息必须写进 prompt；困难任务（画星月夜、化学试剂）**只有在 prompt 里详细描述形态与任务后才成功**。这意味着"协议形态无关"的优雅性有一部分被 prompt 工程抵消了——换机器人不用重训，但要重写 prompt，且效果对措辞敏感。
5. **不输出动作块是结构性短板。** 每轮只给一个末端位姿，复杂运动要拆成多轮；精度部分取决于控制器（作者明说控制器差会在某些位置突然运动、错过目标）。这也直接导致"轮数多、token 多、慢"。
6. **评测口径的隐含偏向**：真机试验里"超过 25 轮或单轮推理超 32k token 即失败"——这条规则对长思维链方法是**自己给自己设的紧箍**，但也意味着成功率对算力预算敏感；换更宽松的预算，数字会变。
7. **zero-shot RoboDojo 的 17.0%（align blocks）其实很低。** 论文用 13.0%→17.0% 呈现，看着是提升，绝对水平仍是"基本不会"。整段迁移叙事里，真正扎实的只有 general pickup（10.7%→39.9%）与 Long（0.4%→39.0%）。

## 5. 个人收获

- **最大的启发是"把动作空间挪到模型外面"。** 一旦动作是"末端位姿增量 + 外部 IK/控制器"，模型就与具体机器人解耦，换形态的成本从"重训"降到"改 prompt"。这和 VLA 路线（动作头绑死在关节/末端空间、换机器人要重训）是根本性的架构差异。做多机器人部署时，这个切分值得作为默认选项考虑。
- **二值奖励 + 组归一化 = 必须设计课程。** 这个约束在 RL 里很常见但常被忽略：如果一组全失败，梯度是 0，任务"存在但学不到"。本文的应对（先训有信号的、靠迁移扩边界、把新任务在"开始能成"时加入）是可以直接抄的工程范式。而且它顺手造出了零样本测试。
- **"模仿"与"推理"的差别可以被实验分开。** LIBERO-Pro 的两个扰动设计非常干净：换任务（动作必须变）与换位置（动作必须变）上 VLA 崩、RUA 稳；换措辞/换外观（原动作仍对）上 VLA 稳。这提供了一个可复用的诊断方法：**要判断一个策略是在"执行记忆"还是在"理解任务"，就构造"指令变但场景不变"和"场景变但指令不变"两组扰动。**
- **推理长度是能力的一部分，不是可裁剪的装饰。** low effort 掉到 21.9% 说明这套方法的"能力"与"延迟"是同一个旋钮。任何声称"RUA 能实时控制"的说法，都要先问在什么 effort 下。
- **和已有知识的连接**：RURL 与 CUA 的 RL（DigiRL / WebRL / UI-TARS-2）是同一配方换域；GRPO + 无裁剪 + score-centering 的组合是当下 LLM RL 基础设施的常规形态；"基座模型不会用自己身体、需要 prompt 补形态知识"呼应了具身领域"world knowledge 有、embodiment knowledge 无"的普遍观察；与卡片库里 RAGu（检索增强的零样本适配）、SimVLA（零样本 sim-to-real VLA）相比，本文走的是第三条路——**不改策略、改训练范式**。

## 6. 延伸阅读（可选）

- **π0.5**（Black et al., 2025）：本文最主要的对照 VLA，理解"示教 SFT"路线强在哪、弱在哪的必读。
- **RoboDojo**（Chen et al., 2026）/ **RoboLab-120**（Yang et al., 2026b）：本文的两个迁移目标基准，也可作为自建评测的参考。
- **LIBERO-Plus / LIBERO-Pro**（Fei et al., 2026；Zhou et al., 2025）：扰动鲁棒性评测，本文抗扰动分析的核心工具。
- **UI-TARS-2**（Wang et al., 2025）/ **DigiRL**（Bai et al., 2024）：CUA 侧的多轮 RL 训练，RURL 的方法论来源。
- **DAPO**（Yu et al., 2025）/ **GRPO**（Shao et al., 2024）：组归一化优势与"丢弃全对/全错组"的做法出处。
- **ORA / ASPIRE / Harness VLA / OpenRUA**：本文明确对立的"harness 路线"，读它们能看清两种工程哲学的取舍。
